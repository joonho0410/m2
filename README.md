# 파이썬 기초 문법 퀴즈 게임

터미널에서 동작하는 4지선다 퀴즈 게임입니다. Python 기본 문법(클래스, 파일 입출력, 예외 처리)과 Git 기초(커밋, 브랜치, 원격 저장소)를 익히기 위한 미션 과제로 제작했습니다.

## 프로젝트 개요

- 실행하면 메뉴에서 번호를 선택해 퀴즈를 풀거나, 새 퀴즈를 추가하거나, 등록된 퀴즈 목록과 최고 점수를 확인할 수 있습니다.
- 추가한 퀴즈와 최고 점수는 `state.json` 파일에 저장되어, 프로그램을 종료했다가 다시 실행해도 그대로 유지됩니다.
- 숫자가 아닌 입력, 빈 입력, 범위를 벗어난 입력, `Ctrl+C`/입력 스트림 종료(EOF) 등 다양한 예외 상황을 처리하도록 구현했습니다.

## 퀴즈 주제와 선정 이유

주제는 **파이썬 기초 문법**입니다. 이 미션 자체가 파이썬 기초 문법(변수/자료형, 조건문, 반복문, 함수, 클래스)을 배우면서 진행하는 과제이기 때문에, 배운 내용을 그대로 퀴즈 문제로 만들면 학습 내용을 복습하는 데 가장 도움이 될 것이라 판단하여 이 주제를 선택했습니다.

## 실행 방법

Python 3.8 이상이 설치되어 있으면 별도의 외부 라이브러리 설치 없이 바로 실행할 수 있습니다.

```bash
git clone https://github.com/joonho0410/m2.git
cd m2
python3 main.py
```

실행 후 화면에 표시되는 메뉴에서 번호(1~5)를 입력해 원하는 기능을 선택합니다.

## 기능 목록

1. **퀴즈 풀기** – 저장된 퀴즈를 순서대로 출제하고, 정답 여부를 즉시 알려준 뒤 마지막에 총 결과를 보여줍니다. 결과가 기존 최고 점수보다 높으면 최고 점수를 갱신합니다. 등록된 퀴즈가 없으면 안내 메시지를 출력합니다.
2. **퀴즈 추가** – 문제, 선택지 4개, 정답 번호(1~4)를 입력받아 새 퀴즈를 등록하고 즉시 파일에 저장합니다.
3. **퀴즈 목록** – 현재 등록된 모든 퀴즈의 문제와 정답 번호를 출력합니다. 퀴즈가 없으면 안내 메시지를 출력합니다.
4. **점수 확인** – 저장된 최고 점수를 보여줍니다. 아직 한 번도 퀴즈를 풀지 않았다면 안내 메시지를 출력합니다.
5. **종료** – 현재 상태를 저장한 뒤 프로그램을 안전하게 종료합니다.

공통 입력 처리: 숫자를 입력해야 하는 모든 곳에서 앞뒤 공백 제거, 숫자 변환 실패, 허용 범위 밖 숫자, 빈 입력을 검사하여 안내 메시지를 출력하고 재입력을 받습니다. 또한 `Ctrl+C`(KeyboardInterrupt)나 입력 스트림 종료(EOFError)가 발생해도 프로그램이 비정상 종료되지 않고, 가능한 범위에서 데이터를 저장한 뒤 안전하게 종료합니다.

## 파일 구조

```
misson-2/
├── main.py         # 프로그램 진입점 (QuizGame 실행)
├── quiz.py          # Quiz 클래스: 개별 퀴즈(문제/선택지/정답) 표현
├── quiz_game.py      # QuizGame 클래스: 메뉴, 게임 진행, 파일 저장/불러오기
├── quiz_data.py       # 기본 퀴즈 데이터(DEFAULT_QUIZZES)
├── state.json         # 퀴즈 목록과 최고 점수를 저장하는 데이터 파일 (실행 시 자동 생성)
├── .gitignore
└── README.md
```

## 데이터 파일 설명 (state.json)

- 위치: 프로젝트 루트의 `state.json` (`main.py`, `quiz_game.py`와 같은 디렉터리)
- 인코딩: UTF-8
- 역할: 등록된 퀴즈 목록과 최고 점수를 저장하여, 프로그램을 재시작해도 데이터가 유지되도록 합니다.
- 스키마 예시:

```json
{
  "quizzes": [
    {
      "question": "다음 중 파이썬의 정수형 자료형을 나타내는 것은?",
      "choices": ["str", "int", "bool", "list"],
      "answer": 2
    }
  ],
  "best_score": 7
}
```

  - `quizzes`: 퀴즈 목록. 각 항목은 문제(`question`), 4개의 선택지(`choices`), 정답 번호(`answer`, 1~4)를 가집니다.
  - `best_score`: 지금까지 퀴즈를 푼 결과 중 가장 높은 정답 개수입니다. 아직 한 번도 풀지 않았다면 `null`입니다.

- 파일이 없으면(최초 실행) 기본 퀴즈 데이터(`quiz_data.py`)로 시작하며, 해당 데이터로 `state.json`을 새로 생성합니다.
- 파일 내용이 손상되어 읽을 수 없는 경우(JSON 파싱 실패, 필수 키 누락 등) 안내 메시지를 출력하고 기본 퀴즈 데이터로 복구합니다.

### 여러 프로그램을 동시에 실행했을 때의 데이터 동시성 처리

이 프로그램은 하나의 `state.json` 파일을 여러 프로세스가 함께 사용할 수 있다는 점을 고려해, **저장 직전에 파일을 다시 읽어 최신 내용과 병합한 뒤 저장**합니다(`QuizGame.save_data()`).

- 만약 저장할 때마다 그 시점의 메모리 값(`self.quizzes`, `self.best_score`)을 파일에 그대로 덮어썼다면, 두 프로그램을 동시에 켜고 각각 퀴즈를 추가했을 때 나중에 저장하는 프로그램이 먼저 저장된 내용을 통째로 지워버리는 문제(lost update)가 생깁니다.
- 이를 막기 위해 퀴즈를 추가하거나(`add_quiz`) 점수를 갱신할 때(`play_quiz`) 다음 순서로 동작합니다.
  1. 저장하기 직전, `state.json`을 다시 읽어 그 사이 다른 프로그램이 저장해 둔 최신 퀴즈 목록/최고 점수를 가져옵니다.
  2. 그 최신 데이터 위에 이번에 추가한 퀴즈, 또는 이번에 달성한 점수(기존 최고 점수보다 높을 때만)만 얹습니다.
  3. 합쳐진 결과를 파일에 저장합니다.
- 이 방식(다시 읽고 병합하기)은 파일 잠금(file lock)을 쓰는 방법보다 구현이 간단하지만, "다시 읽는 시점"과 "쓰는 시점" 사이에 아주 짧은 틈이 남아 있어 완벽한 보장은 아닙니다. 다만 이 프로젝트처럼 동시 접속이 드문 개인용 CLI 프로그램에서는 이 정도로 충분하며, 더 강한 보장이 필요하면 `fcntl.flock` 같은 파일 잠금을 추가로 도입할 수 있습니다.
